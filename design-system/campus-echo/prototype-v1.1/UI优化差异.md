# v1.0 → v1.1 UI优化

| 方面 | 本轮实现 |
| --- | --- |
| 校园视觉 | 保留PDF头图与浅蓝色，头图下缘圆角、版面节奏更舒展 |
| 内容可读 | 白色正文卡、36rpx圆角、轻阴影；不在文字后叠折射层 |
| 导航 | 四项浮动玻璃Tab、青色选中胶囊、底部安全区 |
| 功能操作层 | 搜索与底部按钮区使用近白玻璃、亮边和柔影 |
| 无障碍 | 44px触控、深色正文、可见状态文字；减少透明度单独开关 |
| 动效 | 按压120ms、筛选160ms、弹层220/160ms，可中断，减弱动态移除位移 |
| 兼容 | 无backdrop-filter使用近白实色，不依赖Web框架/折射滤镜 |
| 业务 | 全部沿用首轮范围，无新增支付、搜索、点赞或聊天 |

该原型先完成后交给原生页面实施。浏览器材质效果不证明微信或真机完全一致。
