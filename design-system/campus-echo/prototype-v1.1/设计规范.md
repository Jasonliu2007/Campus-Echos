# 校园回声设计规范 v1.1

版本：2026-11-11。原型视觉承接用户提供的《校园平台手机端界面设计稿》，业务采用本地 Core MD 与本轮确认范围。先完成设计与状态，再实现小程序。

## 统一视觉

| Token | 值 | 用途 |
| --- | --- | --- |
| primary | #0878BD | 主操作、选中导航、链接 |
| text | #102D46 | 正文、标题 |
| muted | #567184 | 辅助说明 |
| background | #EEF6FA | 页面浅色底 |
| surface | #FFFFFF | 卡片、表单、底栏 |
| border | #D5E4EE | 卡片和控件边界 |
| selected | #D4F2F7 | 筛选和点选状态 |
| danger | #B83D49 | 删除、失败文字 |
| success | #087D72 | 成功、获准状态 |

- 微信原生小程序，rpx基准750；原型基准390×844逻辑像素。原型中系统时间、微信胶囊仅示意；实现采用真实原生导航，不自行绘制或叠加。
- 原生界面顶部标题为“校园回声”，业务子页显示明确页面名称。主入口四项：校园墙、学习资料、找搭子、我的；AI挑笔记是学习资料二级页面。
- 字体使用系统中文字体，不下载网页字体。正文30rpx，行高1.6；页标题44–52rpx，卡片标题32rpx，辅助24rpx。大字体允许换行，不靠固定高度裁剪正文。
- 页面左右32rpx；4/8逻辑像素节奏：8、16、24、32、48rpx。卡片内边距28–30rpx，卡片间距24rpx；分节间距40–48rpx。
- 正文卡片圆角36rpx、输入框32rpx；常规按钮30rpx；图标采用同一套1.7px描边SVG，无emoji结构图标。原型图标已放 static/campus/。
- 公共校园头图 static/campus/campus-header.jpg，从原PDF无文字的右侧校园区域裁切；配左向淡蓝渐层，不将文字烘焙进背景。主入口hero约300–346rpx；较长表单用原生子页标题而不重复大hero。
- 卡片白底细浅蓝边框，主按钮实色明蓝白字，选中筛选青色深字。避免重阴影、荧光色、大幅装饰动效和各页自定义色。
- 触控区域至少44逻辑像素；相邻触控留8逻辑像素。列表滚动需为Tab和固定按钮留出安全区及额外底部padding。

## 统一组件与行为

- Hero：品牌小字、主标题、短说明、共享校园插画。
- Card：作者/时间、固定分区、标题与正文摘要、详情入口。不显示未接入的假点赞评论数。
- Chip：浅色边框未选、青色实底选中；分区横向可滚动。
- Notice：蓝色说明、暖黄待审、浅红错误；状态除了颜色还需明确文字。
- Form：可见标签、必填标记、限制说明、字数计数、字段附近错误。失败保留全部输入，提交中锁定按钮；有草稿时离开需要明确处理。
- Empty/Error/Loading：同组背景与组件，空状态给下一步，错误有重试，加载骨架保留空间；分页失败保留已加载内容。
- Sensitive action：删除、撤销、下架/驳回用确认与明确后果，成功后状态在当前流程可见。
- 主界面演示模块必须显示“演示内容”；未经实现的购买、上传、加入、搜索等给开放说明，不假装成功。
- 资格只称“封闭内测资格”，不称“学生实名认证”。未批准账号只能申请/查看资格；管理工作台仅管理员可见，但安全边界由服务端校验。

## 动效规范

- 按压反馈120ms，缩放0.98或透明度，布局不变；筛选颜色160ms。
- 弹层进入220ms、退出160ms，缓动cubic-bezier(.22,1,.36,1)；仅transform/opacity或颜色。
- 页面进退采用微信原生导航动效，不再叠加整页动画。列表和常用Tab切换不强制入场动画。
- 禁止transition:all、布局属性持续动画、装饰循环和持续will-change。加载指示可循环，离开状态即停止。
- 原型支持prefers-reduced-motion和设置页减弱动态；小程序若无法可靠读取系统偏好，应用内开关立即禁用自定义位移动画。

## 审查规则

ui-ux-pro-max负责触控、对比度、导航与一致性；ui-animation负责动效与中断；ui-audit在真实实现后检查本批页面。React hooks、DOM、Next边界、Lighthouse数值不套到小程序；对应检查Page.data状态、setData竞态、原生控件与无障碍、键盘/安全区、返回和输入保存。

当前仅浅色主题；未设计暗色模式，不宣称通过暗色检查。原型与代码按本版本配套，每批改动同步索引和开发日志。


## v1.1 液态玻璃操作层（用户 2026-11-11 新增方向）

保留PDF的浅蓝校园与白色界面。参考苹果材料层级与即时反馈：玻璃用于导航、搜索与底部动作层；帖子、资料正文、表单与审核内容保持实色白底，避免文字透底与多重半透明叠加。不是像素级复刻iOS液态折射，不引入WebGL或SVG滤镜。

| 组件 | 设计与原生实现值 |
| --- | --- |
| 玻璃底色 | rgba(255,255,255,.88)，无blur时降级#FDFEFF |
| 模糊 | backdrop-filter:blur(18px) saturate(140%)；仅功能浮层，禁止blur动画 |
| 高光边缘 | 1px rgba(255,255,255,.98)，必要时外描边#D5E4EE |
| 浮层阴影 | 0 8px 24px rgba(32,77,111,.10)，内顶白高光 |
| 浮动Tab | 左右24rpx，距底safe-area+12rpx，外圆角46rpx，四项等宽，item>=44逻辑像素 |
| Tab选中 | 青色胶囊#D4F2F7、深蓝文字/图标、160ms颜色反馈；无额外循环或夸张弹跳 |
| 卡片 | #FFF；细边#D5E4EE；圆角36rpx；0 3px 12px rgba(43,92,125,.024) |
| 原生导航 | 继续微信原生白导航和胶囊，不另画系统控件 |
| 触控 | >=44逻辑像素，不按88rpx推断小屏合格；正文和大字体自然换行 |

- 内容区为浮动Tab/底部操作层保留至少236rpx与safe-area，最后一张卡片和焦点输入不得遮挡。
- 主按钮#0878BD配白字，正文#102D46、辅助#567184；近白玻璃上按白底验对比。错误、待审、演示含明确文字。
- 设置新增“减少透明度”，独立于“减弱动态效果”；启用后浮层实色白、蓝灰边、无blur。小程序读不到系统透明度偏好时，用应用内开关。
- 不支持backdrop-filter仍保留近白实色、边界、圆角和阴影，功能完整；Android和低端真机性能待实际测，不宣称原型证明。
- 按压120ms scale(.98)/opacity；筛选/Tab160ms；确认层进220ms/出160ms，只transform/opacity。保持原生页跳转，不再叠加整页移动。
- 模态关闭可被新导航中断：清理旧定时器；返回同路径，无布局属性动画。减弱动态关闭位移和自定义进入动画，保留状态文字。
- 玻璃视觉的前后版本原型都保留，v1.1为本轮UI实施依据；后端业务无变化。

## 规范来源与取舍

已执行ui-ux-pro-max“campus community mobile light blue translucent navigation accessible native”设计系统查询与动画/无障碍验证查询。采用其高对比、44px触控、焦点与减弱动态原则；不采用其西文字体/金色强调/热门主题建议，因原PDF和Core MD优先。苹果材料原则采用功能层级、可中断反馈与减少透明度；微信原生控件保留平台行为。


## v1.1 审计细化

- 表单输入、正文输入与分区选择最少16逻辑像素，较大画板保持30rpx尺度；小屏不缩小到难以辨认。
- 微信实现采用aria-role和明确的“已选择/未选择”标签，原生设置整行label关联switch。原型用浏览器对应语义；真机读屏需复测。

- 管理表单输入保护：处理原因未提交时，切换筛选、改选其他成员或取消编辑均先确认放弃；取消确认保留原因，同一成员重复点击不重置。离开页使用微信原生提醒，处理失败保留输入。复用第28页未保存离开状态，不增加业务规则。

- 动效最终细化：自定义按钮按下60ms、恢复120ms；筛选颜色160ms，位移使用同一cubic-bezier(.22,1,.36,1)。无自定义入场层，原生确认/页面不声明时长控制。减少动态路径仍即时。
